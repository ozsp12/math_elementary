# Futurama, Banach--Tarski, and Divergent Series

This directory contains the written and computational material associated with a YouTube video connecting a mathematical reference in *Futurama* with the Banach--Tarski paradox and the behavior of divergent series.

## Main materials

- [`graphics_benderama_banach_tarski.ipynb`](graphics_benderama_banach_tarski.ipynb): computational notebook used to produce graphics for the exposition.

The directory serves as the public companion archive for the video. It combines mathematical exposition, references, and computational illustrations related to the episode and the underlying mathematics.
