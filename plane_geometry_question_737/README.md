# Plane Geometry: Circumference Arcs and Tangent Circles

This directory contains the presentation and article associated with two YouTube lessons on a plane-geometry problem involving circumference arcs and a chain of tangent circles.

- [`paper_circumference_arcs_chain_tangent_circles.pdf`](paper_circumference_arcs_chain_tangent_circles.pdf): article-style exposition.

The directory serves as the public companion archive for both videos. The presentation supports the visual explanation, while the paper provides the extended mathematical treatment.
