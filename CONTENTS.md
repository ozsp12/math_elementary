## File conventions

The repository uses several file types:

- `.ipynb`: principal computational notes and tutorial sources;
- `.tex`: LaTeX source or notebook export;
- `.pdf`: formatted lecture notes, presentations, articles, or problem statements;
- `.png` and `.jpg`: figures and illustrations;
- `.gif` and `.mp4`: animations and rendered demonstrations.

A directory may contain both source and rendered material because the repository also serves as a public teaching archive. The source notebook or manually written LaTeX file should be treated as the canonical editable document whenever available.
