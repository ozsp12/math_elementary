# Elementary Mathematics: Lecture Notes and Tutorials

This repository is a personal collection of lecture notes, mathematical tutorials, worked problems, computational demonstrations, visual proofs, and supporting media. The material ranges from elementary mathematics to calculus, differential equations, inequalities, geometry, and mathematical visualization.

The repository is not intended to be a software package or a single linear course. Each directory is a self-contained topic or teaching unit and may contain Jupyter notebooks, PDF notes, LaTeX sources, figures, animations, or video exports.

## How to use the material

1. Open [CONTENTS.md](CONTENTS.md) and select a topic.
2. Read the local `README.md` when one is available in the topic directory.
3. Use the notebook as the main computational document.
4. Consult the PDF files for formatted lecture notes or article-style exposition.
5. Open GIF or MP4 files only when the topic includes an animation or video demonstration.

The notes are written in English, Portuguese, or a mixture of both, depending on the original audience. Mathematical notation and code are generally presented using LaTeX, Python, SymPy, NumPy, SciPy, and Matplotlib.

## Repository policy

The repository is maintained as a public archive of teaching material. Existing directories are kept stable whenever possible so that links from articles, videos, and social-media posts remain valid. Reorganization is therefore performed primarily through indexes, local documentation, and consistent naming rather than large-scale file moves.
